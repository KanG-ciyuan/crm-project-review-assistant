# 工具页与主页主题对齐设计

## 目标

让分析工具页与产品主页保持同一套蓝白视觉基调，避免用户从主页进入工具后出现绿色主题跳变。

## 保留内容

- 保留当前工作区布局、分组导航、报告预览抽屉和响应式结构。
- 保留当前导航切换、指标、进度和抽屉动效节奏。
- 保留风险红、待复核黄和经营观察等语义状态色。
- 不修改导入、规则分析、筛选、人工复核、报告生成或下载逻辑。

## 颜色规则

- 工具页主色直接复用主页的蓝色体系，不再维护独立绿色主色。
- 主按钮、选中状态、链接、焦点轮廓、进度条和强调数字使用主页蓝。
- 侧栏使用白色或浅灰白背景，品牌标识和主要操作使用蓝色。
- 页面背景、卡片和边框保持中性白灰，避免界面被单一蓝色覆盖。
- 报告预览抽屉沿用工具页蓝白基调，语义状态色不被主色覆盖。

## 验收标准

- 从主页进入分析工具时，主色、按钮和选中态没有绿色跳变。
- 桌面与 390px 手机宽度下均无横向页面溢出或文字遮挡。
- 键盘焦点在浅色背景上保持至少 3:1 的可见对比。
- `prefers-reduced-motion` 仍可关闭非必要动效。
- 全量测试和生产构建通过，浏览器控制台无相关错误。
