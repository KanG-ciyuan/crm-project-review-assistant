# CRM 储备项目运营复盘助手：产品流程与页面结构图

这不是网页视觉设计稿，而是先把“用户做什么、网页在哪一步处理什么、哪些数据不出浏览器”画清楚的逻辑图。

## 1. 用户使用流程

```mermaid
flowchart TD
    A[用户打开网页工具] --> B[上传 CRM 导出的 .xlsx]
    B --> C{文件和表头是否符合标准模板?}
    C -- 否 --> D[提示：缺少字段或文件无法读取]
    D --> B
    C -- 是 --> E[浏览器本地读取工作表]
    E --> F[预览前 5 行并确认分析阈值]
    F --> G[浏览器本地计算字段校验、统计与规则]
    G --> H[经营概览]
    G --> I[数据质量待核实]
    G --> J[经营风险待跟进]
    H --> K[用户筛选与查看项目明细]
    I --> K
    J --> K
    K --> L[本地生成 Markdown 复盘草稿]
    L --> M[用户编辑、复制或下载 Markdown]

    subgraph 浏览器本地，不上传原始 Excel
      E
      F
      G
      H
      I
      J
      K
      L
      M
    end
```

## 2. 一张 Excel 在网页里的处理路径

```mermaid
flowchart LR
    A[原始 Excel 文件] --> B[浏览器读取]
    B --> C[标准字段检查]
    C --> D[统一日期、金额、概率格式]
    D --> E[规则判断]
    E --> F1[数据质量标签]
    E --> F2[经营风险标签]
    D --> G[汇总统计]
    F1 --> H[清单与图表]
    F2 --> H
    G --> H
    H --> I[Markdown 经营复盘]

    X[客户名称、联系人、电话等敏感原始字段] -. 不进入模型 / 不上传 .-> B
```

## 3. 网页页面结构

```mermaid
flowchart TB
    A[网页工具] --> B[上传与校验页]
    A --> C[分析结果页]
    A --> D[复盘报告面板]

    B --> B1[选择 .xlsx 文件]
    B --> B2[选择工作表]
    B --> B3[字段状态与前 5 行预览]
    B --> B4[本次分析阈值]

    C --> C1[经营概览 KPI]
    C --> C2[部门 / 负责人统计图]
    C --> C3[数据质量待核实清单]
    C --> C4[经营风险待跟进清单]
    C --> C5[按部门、负责人、风险类型筛选]

    D --> D1[本地生成复盘草稿]
    D --> D2[人工编辑 Markdown]
    D --> D3[复制或下载 Markdown]
```

## 4. 规则和 AI 的分工

```mermaid
flowchart LR
    A[固定规则] --> A1[字段缺失]
    A --> A2[金额和日期异常]
    A --> A3[重复项目]
    A --> A4[跟进停滞]
    A --> A5[签约逾期]
    A --> A6[高金额低确定性]

    B[AI：后续可选能力] --> B1[把统计结果写成复盘文字]
    B --> B2[把风险标签整理为跟进建议]

    C[人工业务人员] --> C1[确认异常是否真实]
    C --> C2[确认金额、日期和项目状态]
    C --> C3[决定跟进行动]

    A --> C
    B --> C
```

## 5. V1 边界

```mermaid
flowchart TB
    A[V1 要做] --> A1[标准 Excel 上传]
    A --> A2[本地校验与规则分析]
    A --> A3[图表、清单、Markdown]

    B[V1 不做] --> B1[CRM 直连]
    B --> B2[任意 Excel 自动识别]
    B --> B3[自动修改源数据]
    B --> B4[账户、数据库、多人协作]
    B --> B5[PDF / Excel 正式报告]
```
