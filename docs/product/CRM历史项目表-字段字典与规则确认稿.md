# CRM 历史项目表字段字典与规则确认稿

## 目的与边界

本文件定义“CRM 储备项目运营复盘助手”适配历史项目分析表的字段含义和规则来源。目标输入为 `10-储备项目报备表（跟进中和呆滞）` 工作表。

- 本适配仅在浏览器本地读取 Excel，不上传原始表，也不修改 Excel 或 CRM。
- 本文件不包含真实客户、项目、销售人员或金额数据。
- `11-近一年跟进中项目` 缺少稳定的项目编码，不作为第一阶段的主输入。

## 字段映射

| 历史表字段 | 产品内部字段 | 处理规则 |
|---|---|---|
| 项目编码 | 项目编号 | 作为项目唯一匹配键；空值或`无`判定为字段缺失。 |
| 项目名称 | 项目名称 | 空值或`无`判定为字段缺失。 |
| 部门 | 部门 | 用于部门统计与筛选。 |
| 销售经理 | 销售经理 | 用于负责人统计与筛选。 |
| 项目状态 | 项目状态 | 仅接受`跟进中`、`呆滞`。 |
| 储备金额（万元） | 储备金额 | 单位固定为万元；必须为大于 0 的数值。 |
| 最近拜访时间 | 最近拜访日期 | 保留原始日期，用于展示和校验。 |
| 拜访间隔周期（天） | 拜访间隔天数 | 优先采用 CRM 导出值，不由网页重新计算。 |
| 预计合同签订时间 | 预计签约日期 | 使用销售填写的完整年月日。 |
| 成单概率 | 成单概率档位 | 保留原始文字档位，并映射为低、中、较高、临近签约四个语义等级。 |
| 项目类型 | 项目类型 | 第一阶段仅用于分类统计和筛选，不自动产生风险结论。 |
| 行业、区域、省份、项目等级 | 扩展分类字段 | 用于后续统计，不作为第一阶段必填字段。 |
| 最新更新时间 | 最近更新时间 | 暂不参与规则判断，保留为后续数据时效分析字段。 |
| 储备周期 | 储备周期 | 不自动判定风险；大型项目可能天然具有半年至多年的储备周期。 |

## 状态与概率字典

### 项目状态

| 状态 | 业务含义 | 产品处理 |
|---|---|---|
| 跟进中 | 销售正在持续跟进的项目。 | 纳入拜访间隔、签约预期等经营提示。 |
| 呆滞 | 销售手动标记的暂停跟进项目。 | 单独列为“已手动标记呆滞”；不视为数据错误，也不按拜访间隔判定跟进力度不足。 |

已签约、已丢单项目由其他子表管理，不属于该工作表的当前输入范围。

### 成单概率档位

| 原始档位 | 语义等级 | 业务含义 |
|---|---|---|
| 询价类 | 低概率 | 项目处于询价或信息不足阶段。 |
| 1%-50% | 低概率 | 项目前期、信息不明朗或把握较低。 |
| 51%-70% | 中等概率 | 有明确资金出处，已掌握整体情况和决策链条。 |
| 71%-80% | 较高概率 | 决策链和关键人较清晰，已进行方案交流或参与招投文件。 |
| 81%-100% | 临近签约 | 客户决策链清晰，已形成较深合作并预期近期签约。 |

产品保留原始档位，不将其伪造成精确数值。对于“高金额低确定性”提示，仅将`询价类`和`1%-50%`视为低确定性。

## 第一阶段规则

### 数据质量提示

1. 项目编码或项目名称为空、`无`时，标记为`字段缺失`。
2. 储备金额为空、非数值或小于等于 0 时，标记为`金额格式异常`。
3. 项目编码重复，或项目名称、部门、销售经理、创建日期相同时，标记为`疑似重复报备`。
4. 预计合同签订时间早于创建日期时，标记为`日期逻辑异常`。

### 经营提示

1. 仅对`跟进中`项目：CRM 导出的拜访间隔周期大于 30 天时，标记为`跟进停滞`。
2. 对`跟进中`和`呆滞`项目：预计合同签订时间早于分析当天时，标记为`签约预期失效`，提示销售更新项目预期或状态。
3. `呆滞`项目单独列入“已手动标记呆滞”清单与报告统计，不混入数据错误，也不因为拜访间隔再次标记为跟进停滞。
4. `储备周期`不作为自动风险标签；不使用现有 V0.1 的“长期储备待复盘”规则。

### 重点观察线索

“高金额 + 低确定性”不作为硬性风险标签，也不计入风险项目数量。原因是单次导入数据的 75 分位会随项目结构变化，不能稳定代表业务阈值。

第一阶段仅生成“低概率重点项目”观察清单：

1. 筛选成单概率为`询价类`或`1%-50%`的项目。
2. 按储备金额从高到低展示，供人工判断是否需要优先复核。
3. 不暗示金额或概率填写错误，也不自动要求销售修改。

在积累至少 3 次真实复盘结果后，再将人工审查结论与项目类型、项目等级、金额、最终状态对照，决定是否为不同项目类型建立可解释的重点观察阈值。阈值必须在页面可见、可调整，不能由单次导入自动改变。

## 页面与报告调整

1. 总览指标改为：项目总数、跟进中、已手动标记呆滞、跟进停滞、签约预期失效、数据质量待复核。
2. 异常清单保留“数据质量”和“经营提示”筛选，并新增“已手动标记呆滞”查看入口。
3. Markdown 报告将“已手动标记呆滞”独立统计，不把它描述为系统自动判定的异常。
4. 现有人工审查状态、处理说明与本地保存机制继续沿用。
5. “低概率重点项目”以独立观察清单呈现，不计入经营风险数量。

## 验收标准

1. 用户无需手动改列名，即可导入目标工作表。
2. `跟进中`项目的拜访间隔大于 30 天时出现跟进提示；`呆滞`项目不触发此提示。
3. 两类状态的项目在预计合同签订日期已过时，都出现签约预期更新提示。
4. `无`项目编码或项目名称被正确标记为字段缺失。
5. 成单概率档位保持原始文本，低概率观察清单仅覆盖`询价类`、`1%-50%`，并按储备金额排序。
6. 储备周期较长的项目不会被自动认定为风险或呆滞。
