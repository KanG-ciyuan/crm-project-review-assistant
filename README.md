# CRM 储备项目运营复盘助手

将不同 CRM 导出的项目 Excel 转化为可复核的问题清单和经营复盘报告的浏览器工具。

**在线体验：** <https://crm-project-review.pages.dev>
**脱敏示例表：** [下载 `.xlsx` 示例](./sample-data/CRM历史项目表-脱敏适配样表.xlsx)

## 项目背景

在传统 CRM 项目运营中，项目明细通常需要从系统导出后，再由运营人员手动套公式、筛选异常、汇总图表，并整理为日报或周报。这一过程重复、依赖个人经验，且容易遗漏应复核的项目。

本项目将其中可明确表达的判断沉淀为固定规则，并通过字段映射适配不同企业的 Excel 表头：

```text
导入任意项目 Excel → 确认工作表与表头 → 映射字段和业务口径 → 规则扫描 → 筛选复盘 → 导出报告
```

## 核心设计

### 不让 AI 猜业务风险

系统不使用大模型直接判断项目好坏。跟进停滞、预计签约逾期、字段缺失、金额复核等问题均由明确规则产生提示；业务人员再结合真实情况确认“数据错误”“业务风险”或“已忽略”。

这样可以保留判断依据，避免把模型推测当作业务结论。

### 数据默认留在浏览器

- 原始 Excel 在浏览器本地解析，不上传到服务器。
- 审查状态和处理说明保存在当前浏览器；刷新后可恢复，跨浏览器和跨设备不会同步。
- 仓库内的项目名称、负责人和区域均为虚构演示数据，不对应真实 CRM 客户或人员。
- CRM 始终是正式数据源。本工具只负责检查、分析和复盘，不修改原 Excel，也不回写 CRM；真实修正仍由业务人员在源系统完成。

## 当前能力

- 导入任意未加密的 `.xlsx` 文件，选择需要分析的工作表和实际表头行。
- 将每个源字段设为“标准字段”“自定义字段”或“忽略此列”；未识别字段默认保留为自定义字段。
- 逐项统一企业自己的项目状态、成单概率和金额单位，确认后再运行规则。
- 在分析前展示每条规则是否可执行；缺少字段时只跳过对应规则，不阻断其他分析。
- 汇总项目数量、储备金额、项目状态以及部门、销售经理、跟进周期、储备周期和概率结构。
- 将结果分为五个区域：数据质量待复核、维护超期待整改、疑似重复与撞单、重点项目复盘、经营结构分析。
- 支持部门、销售经理、状态、概率、金额、周期、规则标签、审查状态及自定义字段等全局筛选。
- 筛选结果会同步影响概览指标、汇总、五类结果和经营复盘报告。
- 支持人工填写审查状态与处理说明，并分别导出“当前筛选结果”和“全部结果”的 Markdown 报告。

## 导入与字段映射

工具不再要求所有企业使用同一套 CRM 表头。导入流程分为四步：

1. 选择工作表并确认表头所在行。
2. 将企业自己的列名对应到项目名称、客户名称、销售经理、状态、金额、日期等标准字段；业务特有列可保留为自定义字段，不需要分析的列可以忽略。
3. 将 Excel 中的状态、概率原值统一到工具口径，并确认整张表使用的金额单位。
4. 查看可执行规则和跳过原因，确认后开始分析。

标准字段包括项目编号、项目名称、客户名称、部门、销售经理、项目状态、储备金额、金额单位、创建日期、最近跟进日期、预计签约日期、成单概率、行业、区域、项目类型、项目等级和最后更新时间。并非所有字段都必须具备；缺少某个字段时，依赖它的规则会明确显示为不可执行。

详细规则见 [字段字典与规则确认稿](./docs/product/CRM历史项目表-字段字典与规则确认稿.md)。

## 规则能力

- 跟进中和手动标记为呆滞的项目，最近一次有效跟进超过 30 天时提示“跟进超期”。
- 在途项目预计签约日期早于分析当天时提示“签约日期超期未更新”。
- 检查金额空值、非数字或不大于 0，以及创建日期、最近跟进日期和预计签约日期之间的逻辑异常。
- 金额达到 1000 万、5000 万和 1 亿元时分别进入重点、超大和极端金额复盘。
- 同一销售存在至少 5 个相同金额项目时提示“疑似占位金额”。
- 检查重复记录、同客户同名项目以及跨销售的疑似撞单。
- 询价类、低概率、181 至 365 天储备周期属于经营观察；超过 365 天进入长期储备复核，不直接等同于业务风险。

所有规则结论均可解释、可追溯。工具负责发现需要关注的线索，最终业务判断仍由管理人员确认。

## 快速体验

1. 打开 [在线体验地址](https://crm-project-review.pages.dev)。
2. 下载或上传脱敏示例表。
3. 选择工作表，依次确认表头、字段对应关系和状态、概率、金额单位口径。
4. 在确认页查看规则执行范围，点击“开始规则分析”。
5. 使用部门、销售经理等筛选器缩小复盘范围，在结果区域确认审查状态并补充处理说明。
6. 查看同步更新的经营复盘草稿，按需导出当前筛选结果或全部结果。

## 技术实现

- React + TypeScript + Vite
- SheetJS / `xlsx`：浏览器本地解析 Excel
- `localStorage`：保存审查状态和处理说明
- Cloudflare Pages：静态站点部署
- Vitest + Testing Library：规则、审查状态与关键界面交互测试
