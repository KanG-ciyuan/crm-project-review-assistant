# CRM 储备项目运营复盘助手

将 CRM 导出的标准储备项目 Excel 转化为可人工复核的数据质量问题、经营风险清单和经营复盘草稿。

## 当前阶段

当前为 V0.5：已完成 CRM 历史项目表适配、人工审查处理闭环、字段说明、脱敏样表下载与反馈入口，并发布为公开演示站点：<https://crm-project-review.pages.dev>。

原 Workers 地址仍保留，但建议使用 Pages 地址访问和演示。

## 数据边界

- 仅提交脱敏模拟数据，不提交真实 CRM 导出、客户资料或联系人信息。
- 不提交 API Key、令牌或本地环境配置。
- V1 计划在浏览器本地解析 Excel 和执行规则。

## V0.2 审查闭环

- 审查状态和处理说明仅保存在当前浏览器；刷新页面后重新导入同一项目，记录会自动恢复，跨浏览器和跨设备不会同步。
- 同一项目关键字段未变化时保留审查结论；储备金额、金额单位、项目状态、成单概率或关键日期变化时，保留历史并回到“待复核”。
- 页面不会修改 Excel，也不会回写 CRM；业务人员仍应在 CRM 中完成真实的数据修正与跟进动作。

## 文档入口

- `docs/product/`：产品定义、PRD、流程图。
- `docs/plan/`：中英双语实施计划和工程实施细节。
- `sample-data/`：脱敏模拟数据与字段说明、测试预期结果。
- `design/`：静态 UI 概念稿。
- `CHANGELOG.md`：已完成阶段、关键决策、验证结果和对应提交。
