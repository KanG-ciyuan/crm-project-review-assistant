# CRM 储备项目运营复盘助手

将 CRM 导出的储备项目 Excel 转化为可复核的问题清单和经营复盘草稿的浏览器工具。

**在线体验：** <https://crm-project-review.pages.dev>
**脱敏示例表：** [下载 `.xlsx` 示例](./sample-data/CRM历史项目表-脱敏适配样表.xlsx)

## 项目背景

在传统 CRM 项目运营中，项目明细通常需要从系统导出后，再由运营人员手动套公式、筛选异常、汇总图表，并整理为日报或周报。这一过程重复、依赖个人经验，且容易遗漏应复核的项目。

本项目将其中可明确表达的判断沉淀为固定规则，形成一条可解释的复盘流程：

```text
导入 CRM Excel → 校验固定字段 → 规则扫描 → 人工审查确认 → 生成并导出 Markdown 复盘
```

## 核心设计

### 不让 AI 猜业务风险

系统不使用大模型直接判断项目好坏。跟进停滞、预计签约逾期、字段缺失、金额复核等问题均由明确规则产生提示；业务人员再结合真实情况确认“数据错误”“业务风险”或“已忽略”。

这样可以保留判断依据，避免把模型推测当作业务结论。

### 数据默认留在浏览器

- 原始 Excel 在浏览器本地解析，不上传到服务器。
- 审查状态和处理说明保存在当前浏览器；刷新后可恢复，跨浏览器和跨设备不会同步。
- 仓库内的项目名称、负责人和区域均为虚构演示数据，不对应真实 CRM 客户或人员。
- 页面不修改原 Excel，也不回写 CRM；真实修正仍由业务人员在源系统完成。

## 当前能力

- 导入 `.xlsx` CRM 储备项目表，并选择工作表。
- 校验 11 个固定字段及基本填写约定。
- 汇总项目数量、储备金额、部门与销售经理金额分布。
- 扫描跟进停滞、签约预期失效、字段缺失、金额复核等问题。
- 将同一项目命中的多个标签合并展示，避免重复统计。
- 支持人工填写审查状态与处理说明，并将结论同步更新到 Markdown 草稿。
- 下载脱敏示例表、下载 Markdown 复盘、复制反馈邮箱。

## CRM 字段约定

当前版本适配以下表头：

`部门`、`销售经理`、`创建日期`、`最近拜访时间`、`拜访间隔周期（天）`、`项目名称`、`项目编码`、`项目状态`、`成单概率`、`储备金额（万元）`、`预计合同签订时间`。

其中，`项目状态`目前使用“跟进中”和“呆滞”；“呆滞”是销售手动标记的运营状态，不由系统自动判定。跟进中项目的拜访间隔超过 30 天会被提示复核；低概率项目进入观察清单，不直接计为风险。

详细规则见 [字段字典与规则确认稿](./docs/product/CRM历史项目表-字段字典与规则确认稿.md)。

## 快速体验

1. 打开 [在线体验地址](https://crm-project-review.pages.dev)。
2. 下载或上传脱敏示例表。
3. 选择“CRM 历史项目表”工作表，点击“开始分析”。
4. 在异常项目列表中确认审查状态，并按需补充处理说明。
5. 查看同步更新的经营复盘草稿，下载 Markdown 文件。

## 技术实现

- React + TypeScript + Vite
- SheetJS / `xlsx`：浏览器本地解析 Excel
- `localStorage`：保存审查状态和处理说明
- Cloudflare Pages：静态站点部署
- Vitest + Testing Library：规则、审查状态与关键界面交互测试

## 本地运行

```text

src/lib/          Excel 工作簿读取与字段适配
src/App.tsx       页面交互与状态编排
sample-data/      可公开使用的脱敏模拟数据
docs/product/     PRD、字段规则、页面与流程说明
docs/plan/        实施计划与工程记录
CHANGELOG.md      已完成版本与验证结果
```
